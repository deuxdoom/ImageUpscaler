A FEW GOOD ANSWERS

궁금할 수 있는 것들.

사진과 아이콘에는 어떤 모드를 쓰나요?

사진은 사진 AI, 일러스트와 아이콘은 이미지 AI부터 사용해 보세요. 원래 모양을 최대한 유지하고 싶으면 원본 보존, 격자 단위 그림은 픽셀아트가 어울립니다. AI는 표현을 추정하므로 결과를 비교해 선택하세요.

8배는 어떻게 확대하나요?

2배 확대를 먼저 한 뒤, 그 결과를 다시 4배로 확대합니다. AI 모드는 두 단계를 모두 AI로 처리하고 단계마다 손상 검사를 합니다. 결과가 4,800만 픽셀 이하여야 하므로 8배는 약 75만 픽셀(예: 1000 × 750) 이하의 이미지에 사용할 수 있습니다.

이미지가 서버로 전송되나요?

이미지 처리는 PC 안에서 이루어집니다. 업데이트 확인과 새 버전 다운로드만 GitHub에 연결하며, 이미지 파일을 업로드하지 않습니다.

원본 보존 모드는 모든 정보가 그대로인가요?

새 디테일을 AI로 추정하지 않는 확대 방식입니다. 출력은 8bit sRGB이며, HDR·16bit 정밀도와 애니메이션은 지원하지 않습니다. AI의 내부 4배 이미지와 8배 결과를 포함한 작업 이미지는 최대 4,800만 픽셀까지 처리합니다.

실행 위치를 F 드라이브로 제한하나요?

어느 드라이브에서나 실행할 수 있습니다. EXE 옆에 작업 폴더를 만들 수 있는 위치를 선택하세요. F 드라이브 사용 규칙은 개발 작업에만 적용합니다.
